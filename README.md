This is a repository with all my assignments and capstone projects of my PGC AI/ML at University of Texas, Austin. 
You can use them for your own learning process. 
You can also suggest improvements. 
The first Jupyter Notebook, which analyses heart disease, demonstrates a neural network built from scratch using NumPy arrays. It illustrates forward and backward propagation through a largely manual process and compares this approach with the use of libraries. Analysing the structure of a raw neural network is important, as it helps you understand the underlying mechanisms and enables you to scale the network and transition seamlessly to other models.
The second notebook makes a thorough analysis of backward propagation. I added gradient analyses that help deciding which model is prone to vanishing gradients or the opposite.
